# ADR-0014：備援 Rundown 用列印專用網頁

- 狀態：已接受
- 日期：2026-10-20
- 對應：`tech-stack.md` T-C、T21、R5；`sync-and-offline.md` 第 10 節

## 背景

伺服器或網路完全失效時，最後的保險是紙本。總召要能匯出全部角色的 Rundown，各角色也要能匯出自己的；離線時也要能匯出。

## 決定

- 列印專用網頁 `/print`（`@media print`），由瀏覽器列印或另存 PDF。
- 資料來自目前快照；離線時用本機快照。Master 的快照帶完整 CueRole（各角色與備註），Master 版才能從快照產生。
- 頁頭印上匯出時間與 `eventVersion`，方便辨識是否過期。
- LINE 內建瀏覽器一律引導改用系統瀏覽器列印（ADR-0010）。

## 考慮過的選項

| 選項 | 優點 | 缺點 |
| --- | --- | --- |
| 列印專用網頁（採用） | 不需 PDF 函式庫；離線也能用；版面用 CSS 控制 | 列印效果依瀏覽器而異 |
| 伺服器產生 PDF | 版面一致 | 離線時無法匯出；要引入 PDF 與中文字型 |
| 前端產生 PDF | 離線可用 | bundle 變大很多 |

## 後果

- 好處：只要有快照，任何時候都能列印。
- 代價：手機上的列印體驗不一致，所以流程上由總召在活動前一晚於電腦上統一列印（`tech-stack.md` 3.2）。
- 實機結果：iOS 主畫面模式可叫出列印畫面（`tech-stack.md` 5.1）。

# ADR-0002：免註冊：角色連結的 Token 放在網址片段並保留

- 狀態：已接受（iOS 已實機驗證，Android 待驗證）
- 日期：2026-10-20（實機驗證 2026-10-21）
- 對應：`access-control.md` 3.2、3.3；`tech-stack.md` 2.1「Token 與復原碼」、2.2「Web App manifest」、第 5 節

## 背景

使用者是 10～30 位廠商與親友，當天才第一次用，多數人只會點總召在 LINE 傳來的連結。註冊、登入、安裝 App 都會讓人卡住。同一個人可能從 LINE 內建瀏覽器、Safari／Chrome、書籤、主畫面圖示打開，換手機或清資料後也要能直接回來。

## 決定

每個角色一條連結 `https://<host>/#t=<token>`：

- Token 是 128 位元隨機值，伺服器只存 SHA-256 雜湊。
- Token 放在**網址片段**（`#` 之後），**一直留在網址上，不清除**；頁面每次開啟都從網址讀取，不依賴本機儲存。
- API 請求把 Token 放在標頭，不放查詢字串。
- 連結產生即可使用，沒有生效時間；到活動結束自動失效（ADR-0011）。
- 外流時由總召撤銷並重發該角色的連結。

## 考慮過的選項

| 選項 | 優點 | 缺點 |
| --- | --- | --- |
| 網址片段，保留在網址（採用） | 片段不送到伺服器，不進 Referer、存取紀錄與 LINE 預覽爬蟲；從任何入口打開都帶著 Token | 截圖、轉傳、瀏覽紀錄同步會帶出 Token |
| 網址片段，第一次開啟後從網址清除、改存本機 | 截圖不會外流 | 各瀏覽環境的本機儲存不互通，從 LINE 改用 Safari 開、加到主畫面時 Token 就不見了（原設計，2026-10-20 推翻） |
| 放在路徑或查詢字串 | 實作最簡單 | 會進伺服器存取紀錄、Referer 與連結預覽爬蟲 |
| 帳號密碼或簡訊登入 | 外流風險低 | 當天才用的廠商不會註冊；違反免註冊的核心定位 |
| 另設生效時間（`notBefore`） | 婚前外流的連結看不到東西 | 婚前測試與預覽都要繞過；取消後改為活動前顯示「活動尚未開始」 |

## 後果

- 好處：使用者只需要「點連結」；LINE、系統瀏覽器、書籤、主畫面都能直接開。換手機時重點原本的 LINE 訊息即可。
- 代價：接受 Token 外流風險，對策是事後撤銷重發，不是事前遮蔽。因為網址含 Token，前端不得載入任何第三方腳本，並設定嚴格 CSP。
- 之後要注意：網址片段已被 `#t=` 佔用，前端只能用路徑區分頁面（`tech-stack.md` 2.2「路由」）；不提供 Web App manifest，以免 `start_url` 蓋掉帶 Token 的網址（2.2「Web App manifest」）。Android 上的 Token 保留驗證（RISK-1）若不成立，本決定要重新審查。

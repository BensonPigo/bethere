### P1

- Excel、PDF 匯入 Rundown（貼上 CSV 於 M2c）
- 事後紀錄匯出（第一場由開發者以指令從資料庫匯出）
- 音控檔名對照
- 攝影的下一動線卡片

### P2

- 背景推播與震動
- 智慧手錶、耳機提示音
- 一鍵撥號

### 未排入

- 現場調整 Cue 順序（現場可新增、編輯 Cue；刪除改為略過）
- 同時有多個進行中的 Cue

## 3. 限制

- 介面只有繁體中文。
- 核心功能不依賴推播，也不要求使用者「加到主畫面」。
- 支援多場活動、資料互相隔離；不做婚顧公司的多租戶（ADR-0016）。

## 4. 非功能需求

| 代號 | 需求 | 驗證方式 |
| --- | --- | --- |
| NFR-1 | 單場上限 50 人同時在線，一般 10～30 人 | 負載測試 |
| NFR-2 | 總召操作後，95% 的終端在 3 秒內更新 | 負載測試＋實機往返 |
| NFR-3 | 伺服器或網路中斷時，開過頁面的裝置仍能唯讀顯示時程、倒數照跑；總召離線時不能操作並明確提示 | 實機離線測試、婚前演練 |
| NFR-4 | 支援 iOS Safari、Android Chrome 近兩個主要版本，平板為 iPad 與 Android 10～11 吋；iOS／Android 的 LINE 內建瀏覽器在連線時完整可用（離線不保證，ADR-0010） | 實機驗證 |
| NFR-5 | 活動結束後連結立即失效；伺服器端所有副本在活動結束後 90 天內消失（ADR-0011） | 第 85 天人工驗收 |
| NFR-6 | 任何失敗都表現為「離線」，不會讓裝置清掉快照（ADR-0012） | 自動測試 |
| NFR-7 | 時間平移的結果與 `design/data-model.md` 4.2 一致，而且可以精確復原 | 單元測試＋性質測試 |
| NFR-8 | VM 或磁碟故障時，備援操作者 15 分鐘內恢復 | 暫存專案演練 |
| NFR-9 | VM 或磁碟故障時，最多遺失故障前 10 秒內的操作 | 暫存專案演練：寫入後 10 秒內停掉 VM，還原後確認寫入仍在（`operations/runbook.md` 第 2 節） |
